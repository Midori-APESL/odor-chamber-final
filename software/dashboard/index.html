    Reading this plot
    Radius
    Vector magnitude — an intensity-like score in latent space, not a calibrated concentration.

    Source: six real calibration runs (clean air, ammonia, acetic acid, linalyl acetate, thyme oil, rosewater). Method: for each run, dropped rows where the BME688's 10-step gas-resistance vector was just a repeated cached value (not a new sweep) · took each run's own first 15% of sweeps as its personal baseline · log10-ratioed the last 35% of sweeps against that baseline · standardized and ran PCA across all six classes pooled together. PC1 (98% of variance) was excluded — it tracks overall response magnitude, which mostly reflects how far each run's tail window was into its exposure ramp, not compound identity. PC2 and PC3 (the plotted x/y here) capture the relative shape across the 10 heater steps instead — the qualitative fingerprint distinguishing compounds, independent of intensity. To add a class: re-run this same pipeline against a new CSV and paste the resulting points into SAMPLES/CENTROIDS below.
